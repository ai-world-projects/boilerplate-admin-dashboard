Getting started

Install & run

One codebase, two data sources. In development, MSW serves the full API from memory. Point it at a real backend by changing environment variables only — no component or service code changes.

1 · Install & start

Node 18+ and npm. Dev server at localhost:3000.
# from the repo root
npm install
npm run dev      # mocks on
npm run build    # CI gate
npm run start    # serve build

2 · Choose the data source — mock

Set these in .env.local. The switch above previews each mode.

            

          

        

        
How a request flows

          
Components never call a service directly — they go through the feature hook. The last hop is the only thing that changes between modes.

          

          
Auth token rides in a token header; a 401/403 bounces to /login. Every response uses the StandardResponse<T> envelope; lists use Paginated<T> (both defined under Data model).
